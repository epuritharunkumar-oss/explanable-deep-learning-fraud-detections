# Explainable Deep Learning for Financial# FraudShield AI - System Walkthrough & Updates

## Major Upgrade: Real Deep Learning Batch Fraud Analysis & Excel Export

### Problem Addressed
Previously, the Batch Analysis page displayed values directly from the CSV input without performing genuine training or holdout test evaluation, leading to static or leaked predictions. The user required a real Deep Learning Neural Network pipeline with no data leakage, distinct **Actual CSV Label vs AI Predicted Label** columns, real mathematical metric evaluation, Explainable AI sensitivity attribution, and a multi-sheet Excel export.

### What Was Built & Verified

1. **Multi-Modal Tabular Deep Neural Network (`backend/ml/deep_model.py`)**:
   - 4-layer Deep Neural Network: Dense(D $\to$ 64) $\to$ LeakyReLU $\to$ Dropout $\to$ Dense(64 $\to$ 32) $\to$ LeakyReLU $\to$ Dropout $\to$ Dense(32 $\to$ 16) $\to$ LeakyReLU $\to$ Dense(1) $\to$ Sigmoid.
   - He Normal weight initialization and Adam optimizer ($\beta_1=0.9, \beta_2=0.999$, bias-corrected moments).
   - Class-weighted Binary Cross-Entropy to handle fraud class imbalance without synthetic data leakage.
   - Pure NumPy implementation with zero external DLL restrictions under Windows Application Control policies.

2. **No Data Leakage & Reproducible 80/20 Train/Test Split (`backend/ml/train_pipeline.py`)**:
   - Automatically drops ID columns (`transaction_id`, `customer_id`, etc.) and the target column from feature matrix $X$.
   - Validates target column; raises descriptive error if missing (`"Training cannot start because the dataset does not contain a valid fraud target column."`).
   - Evaluates real test metrics (Accuracy, Precision, Recall, F1 Score, ROC-AUC, Confusion Matrix TP/FP/TN/FN) strictly on holdout test partition.
   - Saves model weights, preprocessor, and metrics to `backend/models_saved/`.

3. **Separate Actual vs AI Predicted Label Pipeline**:
   - Distinct columns:
     - `Actual Fraud Label`: Ground-truth label from test CSV.
     - `AI Predicted Label`: Real binary prediction generated by the trained Deep Neural Network.
     - `Fraud Probability`: Raw sigmoid output ($P(\text{fraud} \mid x)$).
     - `Risk Score`: Calibrated $0{-}100$ score.
     - `Risk Level` & `Recommended Action`: Critical ($\ge 81$), High ($61{-}80$), Medium ($31{-}60$), Low ($0{-}30$).
     - `Explainable AI`: Top contributing features and decision narrative.

4. **Multi-Worksheet Excel Export (`/api/export-results` with `openpyxl`)**:
   - Generates `.xlsx` workbook containing:
     - **Worksheet 1 (`AI Predictions`)**: 18 columns including Transaction ID, Customer ID, Amount, Features, Actual Fraud Label, AI Predicted Label, Probability, Risk Score, and Action.
     - **Worksheet 2 (`Model Evaluation`)**: Dataset Name, Total Records, Training Records, Testing Records, Features Used, Model Version, Accuracy, Precision, Recall, F1 Score, ROC-AUC, and Timestamp.

5. **Upgraded Frontend UI (`frontend/src/pages/BatchAnalysis.jsx`)**:
   - Stepped workflow: Upload Dataset $\to$ Train Deep Model $\to$ AI Predictions $\to$ Excel Export.
   - Dataset preview card with column classification badges (Target, Excluded IDs, Numerical, Categorical).
   - "Load Demo CSV Dataset (Ground Truth)" button for instant 1-click loading of the 5,000-row multi-modal dataset.
   - Holdout confusion matrix card and test metric statistics cards.
   - Filterable results table with expandable Explainable AI attribution rows.

## 🌟 Key Features

- **Multi-Modal Feature Ingestion**: Evaluates 5 modalities: Transaction Details, Customer Behaviour, Hardware/Device Signatures, Geolocation Distance Anomalies, and Temporal Velocity/Security Indicators.
- **Deep Learning Prediction Engine**: Sigmoid probability output combined with calibrated risk bands (Low, Medium, High, Critical).
- **Explainable Artificial Intelligence (XAI)**: SHAP-style positive and negative feature attribution bar charts + dynamic natural language decision narrative.
- **Executive Fraud Dashboard**: Interactive Recharts analytics (Ratio Doughnut, 24-Hour Velocity Line Chart, Payment Type Bar Chart, Risk Distribution).
- **Batch CSV Analysis**: Process entire datasets, preview records, score fraud probability in real time, and download result CSVs.
- **Alert Management**: Real-time alerts for High and Critical risk transactions with action triggers (Investigate, Resolve, Block).
- **Audit Reports**: Generate Daily, Weekly, and Monthly intelligence reports with CSV export.
- **Trained Model Details**: View Deep Neural Network architecture, ROC curve, Confusion Matrix, and feature importance rankings.

## ⚡ Quick Start Guide

### 1. Launch Backend API (Python Flask)

```bash
cd backend
python -m pip install -r requirements.txt
python seed_data.py
python app.py
```
*The backend API will start on **`http://127.0.0.1:5000`**.*

### 2. Launch Frontend UI (React + Vite)

```bash
cd frontend
npm install
npm run dev
```
*The web interface will open on **`http://127.0.0.1:5173`**.*

## 🤖 Replacing Demo Engine with Trained Keras / PyTorch Model

To integrate an actual pre-trained Deep Learning model:
1. Save your trained Keras model as `fraud_model.keras` inside `backend/models_saved/`.
2. Update `backend/ml/model_loader.py` to load the `.keras` model or `.pkl` weights.
3. The `FraudPredictor` class in `backend/ml/fraud_predictor.py` will automatically route predictions through your saved model.
